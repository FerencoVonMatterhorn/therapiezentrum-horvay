# Frontend

Die Angular-Anwendung der Website. Die vollständige Dokumentation — Projektstruktur,
neue Seiten anlegen, SEO, Deployment — steht in der
[README im Repository-Root](../README.md).

```bash
npm install
npm start      # Dev-Server auf http://localhost:4200
npm run build  # Produktions-Build nach dist/frontend/
npm test       # Unit-Tests
```
